🎮 Number Guessing Game (Python)

A simple beginner-friendly console-based Python game where the player tries to guess a randomly generated number.

📌 Game Description

The computer randomly selects a number between 1 and 100

The player guesses the number

The game provides hints:

Too Low

Too High

The game ends when the correct number is guessed

Total attempts are displayed at the end

🛠️ Technologies Used

Python 3

Built-in random module
